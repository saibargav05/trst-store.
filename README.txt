TRST FREE CLOTHING STORE — QUICK START

FILES
- index.html: your mobile-friendly store website.
- This demo uses sample products and illustrative CSS garment graphics.

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Find WHATSAPP_NUMBER and replace 91XXXXXXXXXX with your WhatsApp number including country code, digits only. Example format: 919876543210.
3. Find UPI_ID and replace YOUR-UPI-ID@BANK with your real UPI ID. Do not publish the placeholder.
4. Update sample product names, prices, descriptions, size options, and add real product photos if you have them.
5. Test the site and order flow before sharing it with customers.

FREE PUBLISHING OPTION (GitHub Pages)
1. Create/sign in to a GitHub account at https://github.com
2. Create a new public repository named trst-store.
3. Upload index.html (and this README if you like) to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like https://YOUR-USERNAME.github.io/trst-store/
GitHub UI labels can change. You can do these steps from a mobile browser, but a computer is usually easier.

PAYMENTS AND ORDERS
- WhatsApp order button sends the customer details and product list to your WhatsApp. You must confirm stock, delivery, and COD yourself.
- The UPI button opens a UPI payment app with the amount. It is not a verified payment gateway and does not automatically confirm payment on the website.
- Never dispatch an order based only on a screenshot; verify payment in your own bank/UPI app.
- This demo has no stock management, automatic order database, shipping integration, or customer account system.
- For automated card/UPI checkout and order tracking, a payment gateway or ecommerce platform may charge transaction/platform fees.
- Do not collect customer data until you have a suitable privacy notice and a secure order-handling process.
